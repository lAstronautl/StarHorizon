# SS14 UI Editor (StarHorizon)

Визуальный редактор XAML-интерфейсов Robust UI / SS14: открыть существующее окно из репозитория,
поправить его мышкой или собрать своё с нуля и сохранить `.xaml` (+ каркас `.xaml.cs`).
Логика кнопок сюда не входит — редактор генерирует только разметку и заготовку code-behind.

## Запуск

Нужен только Python 3.8+ (без зависимостей).

```
python Tools/_Horizon/UIEditor/ui_editor.py
```

или `run_ui_editor.bat` (Windows) / `run_ui_editor.sh` (Linux/macOS). Откроется браузер на
`http://127.0.0.1:8714` (порт меняется флагом `--port`, `--no-browser` — не открывать браузер).

Можно открыть `static/index.html` и без сервера — тогда работает «автономный режим»: открыть файл
с диска / перетащить `.xaml` в окно и «Скачать» результат (без текстур и локализации).

## Возможности

- **Открыть** любой `.xaml` из репозитория (поиск по пути) или **создать новый** из шаблона
  (FancyWindow, консоль со списком, форма настроек, DefaultWindow, вложенный Control).
- **Холст** с предпросмотром в стиле Nano: BoxContainer, GridContainer, PanelContainer
  (+ `PanelOverride`/StyleBoxFlat), ScrollContainer, TabContainer, SplitContainer, StripeBack,
  Label/RichTextLabel, Button/ConfirmButton/CheckBox/OptionButton, LineEdit/TextEdit, Slider,
  SpinBox, ProgressBar, ItemList, TextureRect (реальные текстуры из `Resources`), SpriteView и др.
  Неизвестные (собственные) контролы показываются фиолетовой пунктирной рамкой и сохраняются как есть.
  Раскладка приближает Robust: `HorizontalExpand`/`VerticalExpand`, `SizeFlagsStretchRatio`,
  выравнивания, `Margin`, `MinSize`/`SetSize`/`MaxSize`, колонки грида, `SeparationOverride`.
- Окно предпросмотра **тянется за правый нижний угол** — удобно проверять, как интерфейс ведёт себя при ресайзе.
- **Перетаскивание**: из палитры на холст или в дерево, перемещение элементов по холсту и дереву.
  Зелёная линия показывает место вставки. Пустой `Control` (распорка) принимает элементы только с зажатым Shift.
  Двойной клик по элементу палитры — добавить в выделенный контейнер.
- **Свойства**: сгруппированные редакторы (bool/enum/цвет/вектор/числа), `StyleClasses` чипами,
  тексты с переключателем `Loc` и подсказкой перевода из `Resources/Locale/<язык>`,
  произвольные атрибуты в «Прочих атрибутах».
- **XAML-вкладка**: правка исходника руками (Ctrl+Enter — применить).
- **C#-вкладка**: каркас `[GenerateTypedNameReferences] partial class` с `RobustXamlLoader.Load(this)`
  и событиями для именованных кнопок/полей ввода (для будущей логики).
- Undo/Redo, копировать/вырезать/вставить/дублировать, обернуть в контейнер / распаковать
  (контекстное меню ПКМ), автосохранение черновика в браузере.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+S / Ctrl+O | сохранить / открыть |
| Ctrl+Z / Ctrl+Y | отменить / повторить |
| Ctrl+C / X / V / D | копировать / вырезать / вставить / дублировать |
| Del | удалить |
| Esc | выделить родителя |
| ↑ / ↓ | по дереву |
| Alt+↑ / Alt+↓ | переместить среди соседей |
| двойной клик на холсте | фокус в поле Text/Title |

## Сохранение и безопасность

Сервер слушает только `127.0.0.1` и записывает только `.xaml`/`.xaml.cs` внутри
`Content.Client`, `Content.Replay`, `Content.Shared`, `Content.Server`.
Существующий `.xaml.cs` при сохранении **никогда не перезаписывается**.
Форматирование файла при сохранении нормализуется (отступ 4 пробела); комментарии сохраняются.

## Как добавить свой контрол в палитру

Допишите запись в `CONTROLS` в `static/schema.js` (тег с префиксом, категория, `children`:
`none`/`single`/`multi`, свойства). Если нужен новый `xmlns`-префикс — добавьте его в `NAMESPACES`,
редактор сам подставит объявление в корень файла при добавлении элемента.
